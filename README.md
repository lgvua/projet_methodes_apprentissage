# Détection du cancer du sein 
Le cancer du sein est l'un des cancers les plus fréquents chez les femmes, et une détection précoce est cruciale pour améliorer les chances de survie. Ce projet exploite des données médicales et des algorithmes d’intelligence artificielle pour analyser des caractéristiques des tumeurs (rayon, texture, périmètre, aire) et prédire si elles sont bénignes ou malignes. L’objectif est de développer un modèle de classification performant pour assister au diagnostic.
